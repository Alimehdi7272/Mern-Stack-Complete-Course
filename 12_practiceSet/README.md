
# Airbnb Clone - Home Rental Web Application

A web application built using Node.js, Express.js, EJS, and Tailwind CSS. It allows users to explore available homes and provides a host section to manage property listings.

## Features

- Browse available homes.
- View home details.
- Add new home listings as a host.
- Edit and manage hosted properties.
- View favourites and bookings pages.
- Responsive user interface using Tailwind CSS.
- Dynamic page rendering using EJS templates.

## Technologies Used

- EJS

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone <YOUR_GITHUB_REPOSITORY_URL>
   ```

2. Navigate to the project directory:

   ```bash
   cd 12_practiceSet
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm start
   ```

5. Open your browser and visit:

   http://localhost:3000
